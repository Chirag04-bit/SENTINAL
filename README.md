# 🛡️ SENTINEL

> **S**mart **E**mergency **N**etwork for **T**hreat **I**ntelligence & **N**etwork **E**valuation **L**ayer

An AI-powered Real-Time Anomaly Detection Dashboard for Financial Fraud Detection, Network Intrusion Detection, and Cybersecurity Monitoring — with Explainable AI, Risk Scoring, and Live Analytics.

---

## 🚀 Overview

SENTINEL is a research-oriented AI/ML project that provides:

- 🔍 **Real-Time Anomaly Detection** — Detect suspicious activities as they happen
- 💳 **Fraud Detection** — Monitor financial transactions for fraud patterns
- 🌐 **Network Intrusion Detection** — Identify cyber threats at the network level
- 🧠 **Explainable AI Alerts** — Understand *why* an alert was triggered (SHAP/LIME)
- 📊 **Risk Score Engine** — Every event gets a 0–100 risk score with reasoning
- 📈 **Live Analytics Dashboard** — Real-time charts, graphs, and threat maps
- 📄 **Report Generation** — Export PDF/CSV reports on demand
